02 Get started

Three commands.
One pocket rig.

Install Termux, pull the binary, point it at a pool. The whole thing fits in a terminal and runs without root.

!

Install Termux from F-Droid. The Play Store build is deprecated and will break package installs.

Get Termux on F-Droid ↗
01

Open Termux and update

Fresh package lists first. This avoids the classic “unable to locate package” detour.

pkg update && pkg upgrade
02

Install Pockethash

One package, one static binary. No Python runtime, no build tools, no browser tab left open.

# install and initialize
pkg install pockethash
pockethash init --worker pocket-01

# point at a pool and run
pockethash run
03

Set your worker

The config stays local. Use a public payout address — never a seed phrase. Start with four threads and a 42 °C guard.

~/.config/pockethash/config.toml 
[pool]
url = "stratum+tcp://pool.example.com:3333"
worker = "pocket-01"
threads = 4
temp_limit = 42

04 The reality check

Your phone will not get rich.
It will get warm.

A flagship phone sustains one to three megahashes. A modern ASIC does hundreds of terahashes. That is roughly a hundred-million-fold gap — before electricity.

Pockethash is for learning how Stratum, shares, nonces, and SHA-256d fit together. It is not a business plan.

05 Questions

The honest
FAQ.

No hype, no “passive income” screenshots. Just what happens when you point a CPU at SHA-256d.

Does this require root or a custom ROM?

No. Pockethash runs entirely in userspace inside Termux. You do not need to unlock the bootloader, flash a ROM, or grant superuser access.

Will it make any money?

Almost certainly not at retail electricity prices. Phones produce a tiny fraction of the hashrate of dedicated ASICs. Treat a share as a successful test, not a paycheck.

Will mining damage my phone?

Sustained heat accelerates battery wear. Use a spare device, keep the thermal limit conservative, and avoid mining on the phone you rely on every day.

Which pools can I use?

Any pool that speaks Stratum v1 and accepts SHA-256d workers. Use a public payout address, verify the pool fee, and never share a seed phrase or private key.

Does it run on iOS?

No. Pockethash is built for Termux and Linux on ARM64 or x86_64. iOS does not allow the background execution or terminal environment required.

Is the demo on this page real mining?

No. The console is a simulation running in your browser. It does not connect to a pool, use your CPU for hashing, or hold a balance. It exists to show the interface.
